Entry for the [make.fun bounty "The Funniest Toaster Error Message"](https://make.fun/bounty/u-eager-stork-81-9647-the-funniest-toaster-error-436406cd).

## The line

> Toasting failed. The bread refused. I respect its decision.

59 characters, one line, deadpan appliance voice: a real error message
("Toasting failed."), a surprise that comes from somewhere the obvious
toaster puns never go (the bread has agency and refused), and nothing wasted.

## How it works

`main.py` (Python 3, stdlib only) writes the single line to
`/output/entry.txt` — no trailing newline, so the file is exactly 59 bytes.
It validates the gate first: 1–120 characters, not only white space, one line.

```sh
python3 main.py
# writes /output/entry.txt
```
